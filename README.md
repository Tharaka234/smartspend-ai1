# SmartSpend AI 📱

A beautiful Flutter application designed to track personal expenses and provide AI-powered financial insights.

## 🚀 Features
* **Expense Tracking:** Log your daily spending by category.
* **Smart Budgets:** Set monthly limits and get notified when you approach them.
* **AI Insights:** Automated tips on how to save more money.

## 🛠️ Tech Stack
* **Frontend:** Flutter & Dart
* **State Management:** Provider / Riverpod
